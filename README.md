# KRISHIMITRA
It is a website where the modern farmers get to find the perfect and suitable crops according to their location. They can test the soil in their nearby soil fertility lab and take down the values and enter those values in our website where they get to know about the suitable crops which can be grown on that soil. 
we are going to add some more features in it like voice assistant and wholesalers contacts or where to sell your grown crops and where you will get more benefit..
